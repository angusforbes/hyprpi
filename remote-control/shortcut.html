📸 Send a screenshot to Thoughts

Once it's set up: take a screenshot → tap its thumbnail → Share (↑) → Send to π. It goes to Thoughts of the world you last wrote to from the phone (else the desktop's), the same as 📎.

Set it up (once, in the Shortcuts app)

  1. Shortcuts → + → name it Send to π.
  2. Tap ⓘ (Details) → turn on Show in Share Sheet. Back in the editor, tap Images and 18 more at the top and leave only Images on.
  3. Add the action Get Contents of URL. Tap its URL and paste the URL above.
  4. Tap › on that action (Show More): Method POST; Headers → Add new header: Key = the header name, Text = the header value; Request Body File → tap File and pick Shortcut Input.
  5. Optional: add Show Notification after it, so you see "Sent to Thoughts-D".

Options

  • A caption: before Get Contents of URL add Ask for Input (Text, "Say something?"), then URL Encode (Provided Input), then add ?caption= to the end of the URL followed by URL Encoded Text.
  • Pick the world: add ?world=D (or any letter) to the URL; or a Choose from Menu with A–E, each with its own Get Contents of URL.
  • From inside π: copy a screenshot, then long-press the message box → Paste: it's attached like 📎.

The phone must be on Tailscale, as for π itself. Photos (HEIC) work too: they're turned into a JPEG on the laptop and saved in ~/Phone.

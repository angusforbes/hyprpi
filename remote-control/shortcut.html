📸 Send anything to Thoughts

Once it's set up: Share (↑) → Send to π, from a screenshot, Photos, Files, Safari or Notes. It goes to Thoughts of the world you last wrote to from the phone (else the desktop's), the same as 📎.

  • Images (screenshots, photos): Thoughts sees them, as with 📎.
  • PDFs, videos, audio, other files: saved in ~/Phone; Thoughts gets the path (it can't watch videos itself, and is told so).
  • Links and text: become the message itself; nothing is saved.
  • Folders: with the second Shortcut below, saved in ~/Phone as one .zip (not unpacked); Thoughts gets the path.
  • Which world: the one π shows on the phone right now (else the one you last wrote to, else the desktop's), unless the URL says &world=.
  • Up to 500 MB each. Anything bigger is refused and the notification says "too big: 500 MB at most".

Set it up (once, in the Shortcuts app)

  1. Shortcuts → + → name it Send to π.
  2. Tap ⓘ (Details) → turn on Show in Share Sheet. Back in the editor, tap the types at the top (Images and 18 more) and turn on Images, Media, PDFs, Files, URLs and Safari web pages. Leave Text and Rich text off (see Tips).
  3. Add the action Get Contents of URL. Tap its URL and paste the URL above.
  4. Tap › on that action (Show More): Method POST; no headers; Request Body File → tap File and pick Shortcut Input.
  5. Optional: add Show Notification after it, so you see "Sent to Thoughts-D".

Set up with the X-Shot-Token header and got "The network connection was lost"?

Replace the Shortcut's URL with the one above, and delete every header row under Headers (swipe left on it). The key is now in the URL, so no header is needed.

Folders: a second Shortcut, "Send folder to π"

iOS can't upload a folder as it is, so this one zips it first. In Shortcuts:

  1. + → name it Send folder to π. Tap ⓘ → turn on Show in Share Sheet; tap the types at the top and leave only Folders on.
  2. Add Make Archive: Make ZIP archive from Shortcut Input. Tap › → Archive Name → Shortcut Input → tap it → Name.
  3. Add Get Contents of URL: paste the URL above. Tap ›: Method POST; Request Body Form → Add new field → File, Key file, value Archive.
  4. In Send to π, turn Folders off at the top, so a folder offers only this one.

Then: Files → long-press a folder → Share → Send folder to π. It arrives as ~/Phone/<folder name>.zip.

Arrives empty ("nothing was shared")?

Check that the File field under Request Body shows the blue Shortcut Input. If it still arrives empty, use a form instead: Request Body Form → Add new field → File, Key file, value Shortcut Input. The file's own name is kept, and a Text field with Key caption adds a caption.

Already set it up for images only?

It keeps working as it is. To send everything else too, one change: open the Shortcut, tap the types at the top (Images) and turn on Media, PDFs, Files, URLs and Safari web pages as well (not Text or Rich text). Nothing else changes: the Request Body stays File → Shortcut Input.

Tips

  • Leave Text and Rich text off. With them on, iOS often sends a stand-in (the page as text or HTML) instead of the link or the file itself.
  • Share a file from outside it: in Files, long-press the file → Share → Send to π. Sharing from inside an open PDF sends the page around it rather than the PDF (π then fetches the PDF from its web address if it has one).

Options

  • A caption: before Get Contents of URL add Ask for Input (Text, "Say something?"), then URL Encode (Provided Input), then add &caption= to the end of the URL followed by URL Encoded Text.
  • Keep the file's name (e.g. "Q3 report.pdf" instead of pdf-20261010-…): before Get Contents of URL add Get Details of Files (Name, of Shortcut Input), then URL Encode it, then add &name= to the end of the URL followed by URL Encoded Text. (No header needed.)
  • Pick the world: add &world=D (or any letter) to the URL; or a Choose from Menu with A–E, each with its own Get Contents of URL.
  • From inside π: copy a screenshot, then long-press the message box → Paste: it's attached like 📎.

The phone must be on Tailscale, as for π itself. Photos (HEIC) work too: they're turned into a JPEG on the laptop and saved in ~/Phone. One item per share: for several at once, wrap Get Contents of URL in Repeat with Each (Shortcut Input) and send Repeat Item.
